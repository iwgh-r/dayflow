# 실제 진행 기록

기준일: 2026-11-18 (Asia/Seoul). 작업 브랜치 `feature/bootstrap-tasks`. 전체 앱은 개발 중이며 TickTick 동등 기능·정밀 화면 재현 완료가 아니다.

## 현재 구현

Windows Compose Desktop와 Android Jetpack Compose에서 공유하는 작업 생성·수정·완료·완료 취소·휴지통·복원, 목록 생성·소속 변경, 날짜, 우선순위, 태그, 검색·정렬, 체크리스트, 로컬 저장 및 오류 보호가 존재한다. 각 기능의 원본 화면 정밀 비교는 대기 중이다.

## 확인된 실행 증거

- 도메인 테스트 8개: 0 실패. 파일 재로드, 저장 실패 롤백, 100개 동시 저장, 날짜 경계, 잘못된 입력, 검색·체크리스트, 손상·파일 잠금, 미래 스키마 거부.
- Desktop Compose 자동 UI 테스트 2개: 0 실패. 생성→편집→완료→휴지통→복원 및 실제 데이터 검색·화면 캡처.
- Android API 35 테스트 AVD의 실제 Activity 테스트 1개: 0 실패. 한글 입력·수정·완료·복원·Activity 재생성. 물리 회전 센서나 삼성 IME 검사는 아니다.
- 별도 백그라운드 검사에서 Android 앱 강제 종료·재시작 후 저장 JSON 일치와 실제 UI의 한글 작업 표시 확인. `artifacts/android-runtime/result.json`, `ui-after-restart.xml`, `tasks-phone.png`에 증거가 있다.
- APK 빌드 및 Android lint 실행 성공. 마지막 확인한 lint 보고서는 오류 0개이며 의존성 업데이트 등 경고가 남아 있다. 경고 수는 최신 보고서를 기준으로 확인한다.
- Windows 런타임 포함 패키징 성공. 이전 패키지의 실제 창 시작을 확인했다. 이후 한국어 요일 지원을 위해 `jdk.localedata`를 포함해 재패키징했으며, 변경 후 눈으로 확인하는 검사는 사용자 선호에 따라 다시 실행하지 않는다.
- 원본 약 185초 영상에서 4초 간격 프레임 46개와 특정 시각의 원본 해상도 이미지를 추출했다. 원본·추출물은 Git 제외이며 실제 비교 합격 증거는 아직 없다.

## 사용자 선호: 백그라운드 개발

2026-11-18 요청 이후 Computer Use·브라우저 조작·마우스·키보드 입력·가시적인 앱/에뮬레이터 실행을 사용하지 않는다. 파일·명령·연결 도구와 창 없는 테스트를 사용한다. 로컬 파일 분석과 저장된 스크린샷 검토는 계속 가능하다. 이 규칙은 AGENTS.md에도 저장했다.

## GitHub

연결된 GitHub 앱 계정은 존재하지만 새 저장소 생성 기능이 없다. 로컬 GitHub CLI는 미로그인 상태다. 사용자가 기기 로그인 승인을 완료했다고 답했으나 CLI 확인에는 반영되지 않았다. 원격 저장소와 PR은 생성하지 않았다. 기존 다른 저장소는 수정하지 않았다. 새로운 브라우저 로그인이나 화면 조작으로 우회하지 않는다.

## 남은 작업

M1의 원본 동작·시각 비교와 실기기 검증이 남아 있다. 다음 구현 묶음은 M2의 저장소 이전·섹션/칸반·하위 작업·노트/백업이다. 반복·알림, 캘린더, 습관·집중·통계, 설정·위젯, Windows↔Android 동기화, 기기 캘린더 양방향 연동, Wear OS는 미구현이다. 마지막 두 기능은 필수 범위다.

별도 에이전트 독립 검수, 전체 참조 화면 비교, 대규모 성능 검사, 실제 삼성 기기·워치 검사는 미실행이다. 자동 빌드 스크립트를 독립 AI 검수나 무기한 개발 서비스라고 부르지 않는다.
