# 화면 명세

초기 앱 화면과 최종 참조 목표를 구분한다. 아래 dp 값은 초기 Dayflow 구현값이며 원본에서 측정한 값이 아니다.

| 화면 | 초기 구조 | 연결 데이터·예외 | 최종 확인할 원본 동작 |
|---|---|---|---|
| 작업 목록 | 850dp 이상 폭에서 248dp 탐색 패널, 제목·검색·행·하단 추가 | 현재 필터/검색/정렬에 해당하는 실제 작업, 0건/검색 실패/저장 오류 | 원본 좁은 레일, 패널 표시, 목록·칸반 전환 |
| 좁은 화면 탐색 | 메뉴 버튼에서 탐색 시트 | 모든 할 일·수집함·오늘·다음7일·목록·완료·휴지통 | 폰의 실제 원본 탐색 자료 필요 |
| 작업 상세 | 편집 다이얼로그, 제목·설명·날짜·우선순위·목록·태그·체크리스트 | 취소는 쓰기 없음, 저장 성공 후 닫음 | V1 54s 도구바·서식·체크리스트·키보드 |
| 날짜 | 월 이동·날짜 선택·오늘/내일, 날짜 해제 | 유효한 LocalDate만 저장 | V1 30s 시간·기간·알림·반복 통합 팝업 |
| 새 목록 | 이름 입력·만들기·취소 | 공백/100자초과/동일 이름 거부 | 폴더·아이콘·정렬·삭제·보관 |
| 로드 실패 | 원본 보존 안내, 수정 화면 미노출 | 손상 파일/미지원 스키마/중복 실행 | 별도 앱 설계 |

칸반·캘린더·습관·집중·통계·설정·위젯·워치 화면은 미구현. 각 단계에서 기능 ID별 별도 상태/전환/접근성 명세를 확장한다. 존재하지 않는 화면을 탐색 버튼으로 위장하지 않는다.
