# 개발 순서

전체 범위를 유지하면서 합격 증거가 있는 단위로 진행한다. 다음 단계로 넘어가도 앞 단계의 시각 검증·실기기 미확인 항목을 감추지 않는다.

| 단계 | 브랜치 예 | 핵심 작업 | 합격 문턱 |
|---|---|---|---|
| M0 기반 | feature/bootstrap-tasks | Kotlin 두 플랫폼, 규칙·명세·영상 분석·검사 도구 | 재현 가능한 빌드, 개인정보 제외 |
| M1 작업 핵심 | feature/bootstrap-tasks | T01~T07, D01, 기본 적응형 화면 | 실제 CRUD/재실행/저장 실패/동시성·UI 테스트, 양쪽 실행 |
| M2 구조·저장 | feature/task-structure | Room/SQLite 이전, 섹션·칸반·하위작업·노트·백업 | 마이그레이션 보존, 드래그·상세 조작 참조 일치 |
| M3 반복·알림 | feature/recurrence-reminders | R01~R05 | 월말·윤년·DST·재부팅·중복·권한 거부·배터리 검증 |
| M4 캘린더 | feature/calendar | C01~C03, 기간·타임라인 | 실제 날짜·기간 이동·겹침·스케일, 태블릿 참조 |
| M5 생산성 | feature/productivity | P01~P05, 고급 필터·템플릿 | 기록 기반 통계, 중단·복원·날짜 경계 |
| M6 완성도 | feature/platform-polish | 설정·위젯·Windows 단축키·접근성·성능 | 폰·태블릿·Windows·다크·IME·큰 글자 회귀 |
| M7 동기화·외부 | feature/sync | D03와 외부 서비스 기능 | 서버 방식·비용 먼저 확정, 충돌·오프라인·삭제 전파 |
| M8 기기 캘린더 필수 | feature/device-calendar | C04~C05 | 실제 권한·공급자·반복 예외·쓰기 되돌리기, 실기기 |
| M9 Wear OS 필수 | feature/wear | W01~W02 | 워치 목록/완료·재연결·중복 방지·타일, 실제 폰+워치 |
| M10 릴리스 | release/personal | 최종 검수·서명·APK·Windows 배포 묶음 | 전체 회귀·원본 비교·업데이트 데이터 보존·미해결 버그 공개 |

단계별 AI 실행: 명세 확인 → 코드 → 자동 검사 → 실패 수정 → 실제 화면 → 참조 비교 → 검수 자료 → 커밋/PR. 같은 원인 세 번 실패하면 로그·가설·다음 해결책을 기록하고 무한 반복하지 않는다.
