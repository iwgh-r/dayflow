# 제품 범위와 역할

기준일: 2026-11-18 (Asia/Seoul)

Dayflow는 개인용 Windows·Android 생산성 앱이다. TickTick Premium에서 사용자가 중요하게 여긴 세부 기능과 화면 흐름을 추적하며 독립적인 이름·아이콘·자산을 사용한다. 원본 앱의 코드나 계정에 접근하지 않는다. AI 기능은 제외한다.

최종 범위는 단순 할 일 목록으로 축소하지 않는다. 캘린더, 반복·알림, 습관, 집중, 통계, 매트릭스, 노트, 칸반, 필터, 테마, 위젯, 백업, 기기 간 데이터 일관성과 확장을 포함한다. 기기 캘린더 양방향 연동 및 Wear OS는 후반 필수 합격 항목이다. 개인용이라도 공식 기능표의 협업·댓글·이메일 연동은 먼저 요구사항에 남기고 구현 범위를 숨기지 않는다.

## AI가 맡는 작업

자료 분석 → 기능 ID와 합격 조건 → 구현 → 빌드 → 자동 조작·저장 검사 → 실제 화면 캡처 → 참조 비교 → 오류 수정 → 검수 → 변경 기록 → 설치 파일.

사용자가 코드를 작성하거나, 프롬프트를 매번 옮기거나, 브랜치를 생성하거나, 오류 로그를 해석해야 하는 절차로 되돌리지 않는다. 현재 대화의 실행 권한과 연결된 도구로 가능한 일을 먼저 진행한다.

## 사용자의 최소 개입

| 시점 | 필요한 사용자 행동 | AI가 선행할 일 |
|---|---|---|
| SDK 설치 | Google SDK 약관 동의 | 공식 약관 제시, 설치 경로 준비. 2026-11-18 동의 받음 |
| 원격 저장소 연결 | 필요할 때 계정 로그인 | 로컬 코드·테스트·검토 가능한 변경 준비 |
| 실제 폰 연결 | USB 디버깅 신뢰 승인 또는 APK 설치 승인 | APK·실기기 검사 목록 준비, 연결되면 설치·로그 수집 |
| 기기 캘린더 | 읽기·쓰기 대상 선택 및 권한 승인 | 권한 거부 처리, 선택 UI, 롤백·충돌 처리 구현 |
| Wear OS | 폰·워치 페어링 및 디버깅 승인 | 워치 빌드·전송 테스트 준비 |
| 외부 과금·공개 배포 | 비용·공개 범위 결정 | 금액·결과물·영향을 검토 가능하게 준비 |
| 최종 사용감 | 실제 사용 후 만족 여부 | 기능·시각·접근성·회귀 검사 결과 제공 |

사용자 비밀번호, OTP, 서명키는 채팅으로 요구하지 않는다. 외부 공개·과금·실제 일정 일괄 변경을 작업 편의상 임의 실행하지 않는다.

## 실행의 한계도 기록

빌드 스크립트는 AI 에이전트를 대신하지 않는다. 한 번 만든 검사 절차로 매 변경을 검증할 수 있지만, 무기한 자동 개발·에이전트 간 인계가 이미 작동한다고 주장하지 않는다. 별도 검수 에이전트가 실행되지 않았으면 독립 검수 미실행으로 남긴다. 클라우드 장기 실행과 로컬 실행은 선택된 환경의 실제 권한·실행 상태를 따른다.
