# 상호작용 명세

| ID | 입력 | 기대 결과 | 실패·취소 |
|---|---|---|---|
| T01 빠른 추가 | 제목 → Enter/추가 | 현재 사용자 목록 또는 수집함에 저장, 오늘 화면이면 오늘 날짜 | 공백 거부, 실패 시 제목 유지 |
| T01 상세 | 행 클릭 → 편집 → 저장 | 제목·설명·소속·태그·날짜·우선순위·체크리스트를 함께 저장 | 취소 시 이전 데이터 유지, IO 실패 시 닫지 않음 |
| T02 완료 | 체크박스 클릭 | 완료 시각 기록·완료 목록 이동 | 휴지통에서는 완료 조작 비활성 |
| T03 삭제 | 휴지통 아이콘 | deletedAt 기록, 활성 목록에서 제외 | 영구 삭제 UI 없음, 휴지통 복원 가능 |
| T03 복원 | 휴지통 → 복원 | 삭제 전 소속·완료 상태 유지 | 원래 목록이 없으면 데이터 검증 실패; 현재 목록 삭제는 미구현 |
| T04 목록 | 이름 입력 → 만들기 | 새 UUID 목록 저장 | 대소문자 무시 중복 거부 |
| T05 검색 | 제목/설명/태그 문자열 | 현재 뷰 안에서 대소문자 무시 포함 검색 | 일치 없음 상태 표시 |
| T05 정렬 | 날짜/우선순위/제목/생성 | 해당 정렬, UUID 최종 tie-break | 날짜 없음은 날짜순 마지막 |
| T06 체크리스트 | 항목 추가/체크/제거 → 저장 | 전체 편집 트랜잭션에 포함 | 저장 전 취소하면 변경 폐기 |
| T07 날짜 | 월 이동/오늘/내일/일 선택 | ISO 날짜 저장 | 날짜 해제는 null, 잘못된 날짜 입력 경로 없음 |
| D01 저장 | 임의 변경 | 저장이 성공한 뒤 상태 공개 | 디스크 실패 시 이전 상태 유지, 원본 초기화 금지 |

오늘에는 연체 작업도 포함한다. 다음7일은 내일부터 오늘+7일(포함)까지이다. 필터와 정렬은 현재 세션 상태이며 재실행 설정 저장은 후속이다. 달력 날짜가 자정을 넘으면 30초 이내 갱신한다.

반복 완료·미루기·시리즈 편집·드래그·장기 누르기·멀티 선택·키보드 전역 단축키는 아직 정의/구현 전이다. 이 기능들을 기본 동작이 있다고 추정하지 않는다.
