# 디자인 기준

브랜드 Dayflow, 초기 accent `#4C6FE8`. 원본 로고·아이콘·브랜드 자산을 복제하지 않는다. Material 아이콘을 초기 기능 표시로 사용한다.

초기 구현: 목록 제목 23sp semibold, 작업 15sp, 메타 정보 11sp. 탐색 항목 14sp. 850dp 반응형 경계, 248dp 탐색 패널. 다크/라이트 팔레트, 최소 아이콘 조작 영역 48dp 목표. 이 값들은 원본 측정 결과가 아닌 초기 구현이며 원본과의 차이를 후속 기록한다.

V1에서 확인한 구성: 왼쪽 좁은 파란 레일, 큰 작업 영역, 중앙 편집/날짜 팝업, 칸반 열, 설정의 좌측 카테고리와 우측 설정. 태블릿·Windows에 이 정보 구조를 반영하되 같은 방향의 실화면 비교 전 시각 합격 금지.

후속 합격 기준: 클릭·터치·키보드 모두 접근, 스크린리더 이름, 200% 글자, 좁은 폭, 가로 화면, 고대비, 다크, 한글 IME, 키보드가 상세 하단 버튼을 덮지 않음, 애니메이션 감소 대응. 고정된 수치 임계값은 기준 화면을 확보한 뒤 정의하고 실제 캡처에서 검사한다.
